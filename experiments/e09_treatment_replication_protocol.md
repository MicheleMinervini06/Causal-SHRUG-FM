# E09 · Replication on Burn Scars and Landslides

Record before execution. Apply the flood [treatment-update protocol](e09_treatment_update_protocol.md) to the frozen E07 positive-beta calibration banks. Use all 263 Burn Scars and 68 Landslides test patches in the original E09 order. Reuse all 5,000 paired assignments per scenario, including Landslides repetition 3133. Its previous E07 exclusion concerned the joint effect sampler. This experiment evaluates the reference bias of raw proxy OLS and uses a different calculation.

- Primary is the paired difference in signed-bias MAE between the frozen proxy-only model and the model with all three scores, under the known confounded assignment. Report the validation-fitted rule and scale as a sensitivity analysis and the randomized assignment as a control. Report the two cohorts separately. A consistently negative paired difference supports replication for this benchmark, with Monte Carlo intervals conditional on the respective fixed cohorts.
- Keep the 0.05 absolute-bias event for Brier. Add a fixed constant forecast for each dataset and assignment strength. Before reading test data in the replication, estimate the event frequency over 5,000 simulated assignments on that dataset's validation cohort, using the standard validation reference scaling and a separate seed (19042). The constant is shared by both calibration methods and by both confounded diagnostics. Evaluate it on exactly the same test assignments. Report event frequency and Brier with paired intervals versus both the proxy-only model and the fixed constant. The fixed threshold may have very little discrimination in Landslides.
- As in floods, check 16 versus 32 quadrature nodes on the first 100 assignments with 2,048 risk draws. Keep 16 for the full run if the primary contrast has the same direction and changes by at most 0.001 MAE. Otherwise retain both orders as a sensitivity analysis. Use 512 risk draws at the full run and compare Brier with its first-half estimate. Track effective sample size of shared calibration rows. E07 density and task-score definitions, frozen posterior hashes, and the E09 cohort reference targets must agree with the original input exports.
