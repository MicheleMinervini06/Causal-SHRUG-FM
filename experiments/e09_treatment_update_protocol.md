# E09 · Updating the confounder calibration with treatment

Record before execution. Start with the frozen E05 Sen1Floods11 calibration and its 88 test patches. Compare the two existing calibrations, proxy only and proxy plus the three scores together. Reuse the original 5,000 paired assignments at seed 42 for each scenario. The estimand is the signed bias of the **raw proxy-adjusted OLS coefficient**, averaged over outcome noise conditional on the assignment. Neither predictive model uses the outcome.

- Primary comparison uses the known simulation assignment and outcome scale, including the fixed reference center and SD of the test cohort. Only these two cohort-level constants are supplied to the predictor. The benchmark isolates the contribution of the scores when the assignment model is known. As a sensitivity check, fit regularized logistic assignment on the 86 validation references and one independent simulated validation assignment (seed 9042, repetition zero). Use the validation center and SD for both the assignment model and the outcome scale in this sensitivity. Report that both the rule and scale change. The randomized arm uses its known constant assignment and the primary scale.
- Use E05 Gauss–Legendre integration with the exact zero atom. Within each shared calibration draw, reweight each patch's nodes by the probability of its observed treatment. Reweight the shared draw once by the product of its marginal treatment probabilities across patches. Average the resulting conditional cohort bias exactly for the discrete grid and report effective sample size of coefficient rows. The oracle bias and test assignments must replay original E09.
- Primary metric is paired MAE of predicted signed bias under confounded assignment. Also report RMSE, the same absolute bias threshold of 0.05, and predicted risk of exceeding the threshold. Sample 512 joint bias draws per repetition and method using common uniforms. Retain a common calibration draw within each simulated cohort, then sample the patches independently given that draw and treatment. Report Brier with Monte Carlo correction for the estimated probabilities, and repeat on the first half of draws to check the magnitude of sampling noise. Report paired 95% Monte Carlo intervals conditional on the fixed cohort.
- Verify the discrete update on an exact synthetic case where the score changes only the spread before observing treatment. Check that treatment leaves the prior unchanged under randomization. Compare 16 and 32 quadrature nodes for the first 100 assignments with 2,048 risk draws. Use 32 for the full run if the change is material for the comparison. Keep the additive E09 result as historical context because its per-event exclusion differs from the shared frozen E05 validation fit.
