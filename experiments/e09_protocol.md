# E09 — Can FM reliability scores warn of residual confounding?

Recorded before running. For each fixed test cohort and treatment assignment, predict the **signed conditional bias** of the coefficient of treatment in OLS with an intercept and the raw FM proxy. Under the E02 outcome law, with standardized reference coefficient 1, the target is exactly the treatment coefficient in the regression of standardized reference on treatment and proxy. This averages over outcome noise conditional on the design. It can vary even under randomization. Measurement error can undermine adjustment for confounding ([Battistin & Chesher](https://discovery.ucl.ac.uk/id/eprint/18227/1/18227.pdf)); the proposed warning is our empirical hypothesis.

- Primary: average entropy versus proxy alone on Sen1Floods11, confounded treatment. Replicate on Burn Scars and landslides. Secondary, one score at a time: mutual information, spatial rarity (negative log density), normalized embedding distance, negative NCDD. Keep all patches. No gate, feature search or outcome enters the diagnostic.
- Reuse E02/E05 test order and seed 42 for 5,000 paired assignments in each scenario (a0=0, a1=1 or 0). Generate independent validation assignments with seed 9042 under the same split-standardized rule. Refit for each assignment using validation labels only. For floods exclude the test patch's event from fitting. For burns/landslides form five Ward groups on test scene coordinates (unit sphere for burns, exported box centers for landslides) and assign each validation patch to the group of its nearest test coordinate. Exclude that group when fitting. Record memberships and sizes. Spatial blocks approximate independence. All score variants use identical partitions and draws.
- Fit ridge regression of signed fraction error (reference minus proxy) on treatment, raw proxy and optionally one score. Standardize the continuous predictors on training observations, imputing an absent score at its training mean; constant or entirely missing columns contribute zero. Use penalty 1 on slopes and zero on intercept, binary treatment in 0/1 units. This is a fixed additive diagnostic. Adding the predicted signed error to the proxy is equivalent to predicting the error alone for the final treatment coefficient, since OLS already includes the proxy.
- For each assignment pool the held-out patch predictions to give **one predicted bias for the whole test cohort** via the same partial regression as the oracle. Convert fraction units to outcome units using the fixed validation reference SD (a global calibration-unit convention). True bias uses the original test reference SD. As a scale sensitivity only, report MAE if the simulator's true outcome slope in raw-fraction units were supplied. The primary warning never receives that test SD. Compare with a constant zero-bias warning as well as with proxy-only.
- Primary metric: MAE of predicted signed bias. Report paired score-minus-proxy MAE and its 95% Monte Carlo interval conditional on the fixed splits. Look for a negative interval and improvement over zero, then check replication. Secondary: RMSE, sensitivity, specificity and positive predictive value for absolute bias above 0.05 (5% of the known effect); report denominators and absent denominators. Treat thresholds as simulation choices. Use the randomized arm as a design control; interpret secondary score comparisons descriptively.
- Verify the target against intercept-inclusive least squares and the coefficient for the noiseless simulated outcome. Check the vectorized ridge prediction against an independently fitted ridge model and all model comparisons against the same assignment IDs. Geographic joins on the burn and landslide auxiliary exports assume matching within-split indices. The same cohorts were previously examined; this is an exploratory simulation, not a general test of exchangeability.
