# E06 · Which measurements should we verify at a fixed budget?

Protocol fixed before the run. On the original Sen1Floods11 cohort, compare five score-based policies with random verification of the same number of patches. The main question is whether targeting verification improves whole-cohort treatment-effect RMSE under confounded assignment.

- Keep all 88 patches in every fit. Restrict **eligibility for verification** to patches with all five scores available so every policy, including random, can choose from the same patches. Use the original E06 score directions and choose patches by highest average entropy, mutual information, spatial rarity, normalized embedding distance or negative NCDD. Break exact ties in ascending patch-ID order. Keep these rankings fixed across assignments. Reference fractions do not enter any rankings.
- Prespecify budgets of 5 and 10 verifications. For each repetition, draw one random order without replacement from the same eligible pool (seed 60642). The first 5 and first 10 form the nested random policies. Reuse the same subsets across assignment strengths within a repetition.
- Replay 5,000 paired E02/E06 treatment and outcome draws at seed 42. The confounded scenario has assignment slope 1 and the randomized control has slope 0. True effect is 1. For each policy, reveal all selected reference fractions jointly and adjust by OLS for the resulting mixed confounder (reference for verified patches, raw proxy for the rest). Also estimate the no-verification and all-reference controls. This local test evaluates verification with partial replacement in OLS. The earlier E06 posterior conditioned the remaining latent fractions on treatment and outcome and answered a single-patch question.
- The primary outcome is treatment-effect RMSE at each matched budget. Also report signed bias, 95% coverage and mean interval width using the same model-based Student-t intervals as the E05 OLS controls. Use paired Monte Carlo intervals for score-minus-random contrasts. Report every score and budget; these intervals quantify precision on the fixed cohort and make no multiplicity adjustment. The historical E06 analysis already examined these patches, so treat the comparison as exploratory.
- Save selected IDs, random orders, individual estimates, the summary, and configuration hashes. Verify the batched OLS against the existing scalar OLS and check the no-verification and oracle controls against archived E05 results.
