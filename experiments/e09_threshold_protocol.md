# E09 · Sensitivity of the bias warning to the threshold

Protocol fixed before execution. Repeat the warning experiment on the same three test cohorts, using the same frozen calibration banks, 5,000 paired assignments per scenario, 16 quadrature nodes and 512 joint bias draws per method. Reuse the bias draws for every threshold within each assignment and method. Compare proxy alone, proxy plus the original three scores, and a constant event probability estimated on validation.

- Common absolute-bias thresholds are 0.025, 0.05, 0.10, 0.20 and 0.50. The effect equals 1 in the simulator.
- The two cohort-specific thresholds are the median and 75th percentile of absolute bias over 5,000 confounded assignments on that cohort's validation set (seed 19042). Apply them unchanged to all test scenarios. The constant forecast for each threshold uses the corresponding validation event frequency under the same assignment strength. Calculate the thresholds and constants before reading the test inputs. Report that validation and test can have different bias distributions.
- Report all thresholds for the known rule, the rule and scale fitted on validation, and randomization. For each threshold report both class counts, AUC, corrected Brier, and paired Brier changes with conditional Monte Carlo intervals. AUC uses ties as half a win and is undefined with only one observed class.
- Interpret ranking primarily at thresholds with at least 5% of assignments on either side. Better AUC with weak Brier indicates improved ranking alongside limited probability accuracy. Consistently weak ranking at thresholds with both classes well represented suggests the current diagnostic has limited discrimination. A clear improvement only when both classes become well represented supports a threshold limitation. These are exploratory comparisons on fixed cohorts and do not determine a universal tolerance.
- Verify that the 0.05 forecasts agree with the archived runs and that risks are nonincreasing with the threshold within each assignment and method. Compare Brier against its 256-draw estimate as a Monte Carlo check.
